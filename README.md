# 🎵 بوت موسيقى تيليجرام | Telegram Music Bot

سورس متكامل وبسيط لبث وتشغيل الصوتيات والمرئيات داخل مكالمات القنوات والمجموعات في تيليجرام باستخدام لغة بايثون.

---

## 🚀 المميزات (Features)
- 🎧 تشغيل الصوتيات بجودة عالية وبدون تقطيع.
- 🔍 البحث التلقائي والتحميل المباشر من يوتيوب.
- 🎛️ التحكم الكامل بالبث (تشغيل، إيقاف، كتم، إلغاء الكتم).
- 🤖 نظام الحساب المساعد الذكي للانضمام للمكالمات.

---

## 🛠️ الأوامر داخل المجموعات (Commands)
- `شغل` أو `تشغيل` + اسم الأغنية: للبحث في يوتيوب وبدء البث.
- `ايقاف`: لإيقاف التشغيل ومغادرة الحساب المساعد من المكالمة.
- `كتم`: لكتم صوت المساعد داخل المكالمة.
- `تحدث`: لإلغاء الكتم وإعادة الصوت للوضع الطبيعي.

---

## 📦 المكتبات المستخدمة (Requirements)
- Python 3.9+
- Pyrogram
- PyTgCalls
- yt-dlp
- FFmpeg (مستند خارجي لمعالجة الصوت)
